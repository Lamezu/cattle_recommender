# 📖 Guía de Usuario - Cattle Recommender

Bienvenido al sistema de recomendación de ganado. Esta guía le ayudará a navegar por la aplicación y entender cómo obtener las mejores recomendaciones para su granja.

## 1. Inicio de Sesión
Para acceder, utilice su identificador de granjero (ID). El sistema cargará automáticamente sus preferencias y su historial de compras.

## 2. El Dashboard Principal
Al entrar, verá cuatro secciones clave:
*   **Recomendadas:** Vacas sugeridas específicamente para usted basadas en lo que otros granjeros similares han comprado.
*   **Similares:** Si ha estado viendo un tipo específico de vaca, aquí verá otras con características parecidas.
*   **Más Compradas/Vistas:** Las tendencias actuales del mercado.

## 3. Interactuar con el Ganado
Al hacer clic en una vaca, podrá:
*   **Ver Detalles:** Edad, raza y precio.
*   **Valorar:** Puntúe con estrellas para que el sistema aprenda sus gustos.
*   **Comprar:** Registre su compra para mejorar las recomendaciones futuras.

---
*Nota: El sistema se actualiza en tiempo real cada vez que usted interactúa con una vaca.*
